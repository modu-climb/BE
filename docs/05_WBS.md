## 일정이 밀릴 때

P7 자동 피드백이 준비되지 않으면 코치가 같은 리포트 형식으로 직접 작성해 이용자 반응 검증을 먼저 진행한다. 데이터 구조가 같아서 나중에 자동 결과로 바꿔도 화면과 비교 지표는 그대로다.

## 검증 지표

- 분석 가능 비율: 제출 영상 중 COMPLETED 비율
- 결과 제공 시간: 업로드 완료부터 리포트까지 중앙값(사용자 대기 제외)
- 홀드 확인 부담: 작업당 사용자가 수정한 홀드 수
- 피드백 타당성: 이용자 이해도 설문, 코치 동의율
- 재사용률: 14일 이내 두 번째 업로드 비율
- 행동 변화: 재시도에서 제안 동작을 시도한 비율
- 영상당 변동비: GPU 초 × 단가 + 저장 비용
